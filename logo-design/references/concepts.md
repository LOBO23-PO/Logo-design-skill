# Concept generation

## Logo types — when to use which

| Type | Best when | Watch out for |
|---|---|---|
| **Wordmark** (name in distinctive type) | Short, distinctive name (≤ ~10 letters); brand recognition through the name itself | Needs real typographic craft to not look like "a font" |
| **Lettermark / monogram** | Long names, initials already used (e.g. law firms, fashion) | Initials alone carry no meaning; must be very well drawn |
| **Pictorial mark** | Clear, ownable object tied to the brand story | Clip-art literalism; generic symbols (globe, lightbulb, swoosh) |
| **Abstract mark** | Tech, finance, multi-product companies; conveys a feeling | Can mean nothing; needs a strong rationale |
| **Emblem / badge** | Heritage, craft, food & drink, schools, clubs | Poor small-size legibility; provide a simplified secondary mark |
| **Combination mark** | New brands that need the name *and* a symbol | Symbol and type must feel like one family |
| **Mascot** | Playful, family-oriented, community brands | Complex; needs a simplified version |

## Idea-generation techniques

1. **Word map.** Write the business, its customers, its values and its origin story. Branch each into nouns, verbs and sensations. Look for crossings between two branches (e.g. *bakery* × *sunrise* → a croissant that doubles as a rising sun).
2. **Letter play.** Look inside the name's letters: counters (the holes in O, A, e), ascenders, the shape of an initial. Can a letter become the object? Can two initials interlock?
3. **Negative space.** Place one shape so that the gap between two others forms a second meaning.
4. **Reduction.** Take a literal object and remove parts until only the essential silhouette remains; stop one step before it becomes unrecognisable.
5. **Metaphor.** Represent the benefit, not the product: security → shield, enclosure, interlock; growth → stepped forms, sprouts, upward motion; connection → overlapping shapes, bridges, links.
6. **Geometry.** Build from circles, squares and triangles only; constraint produces distinctive shapes.
7. **Place & culture.** Local motifs, patterns, architecture, flora — use respectfully and without caricature.
8. **Motion.** Implied movement through rhythm, repetition, or slanted cuts.

## Shape language

| Shape | Common associations |
|---|---|
| Circle, rounded corners | Community, warmth, completeness, friendliness |
| Square, rectangle | Stability, reliability, order |
| Triangle, sharp angles | Direction, energy, ambition, tension |
| Vertical lines | Strength, growth, aspiration |
| Horizontal lines | Calm, stability |
| Organic curves | Natural, handmade, human |

## Concept presentation template

For each concept:

```
Concept A — "<short name>"
Type: combination mark
Idea: <one sentence: what it depicts and why it fits the brief>
Mood: <2–3 adjectives>
```
