# Color and typography

## Building a palette

1. **Primary (1 color).** Carries recognition. Choose by personality, then check it's not owned by a direct competitor.
2. **Secondary (0–2 colors).** Supports the primary; use for accents.
3. **Neutrals.** A near-black (not pure `#000`, e.g. `#16161a`) and an off-white (e.g. `#faf8f5`) give a softer, more designed look.

Keep the logo itself to 1–2 colors plus neutrals. More colors increase print cost and reduce recognition.

### Associations (culture-dependent; use as a starting point)

| Hue | Often reads as |
|---|---|
| Red | Energy, appetite, passion, urgency |
| Orange | Friendly, playful, affordable |
| Yellow | Optimism, sunshine, caution |
| Green | Nature, health, growth, money |
| Teal | Calm, clarity, modern health/tech |
| Blue | Trust, competence, calm |
| Purple | Creativity, luxury, mystery |
| Pink | Playful, caring, bold (saturated) or soft (pastel) |
| Brown / terracotta | Earthy, artisanal, warm |
| Black | Premium, minimal, authoritative |

### Checks

- **Contrast.** Logo vs. intended background should reach at least 3:1 (WCAG non-text contrast). Text in a lockup that must be read should aim for 4.5:1.
- **Grayscale.** Convert the color logo to grayscale: distinct colors with similar luminance merge — adjust lightness, not just hue.
- **Print.** Very saturated RGB blues, greens and oranges fall outside CMYK gamut; give approximate CMYK values and suggest a Pantone match be confirmed by a printer.
- **Color-blindness.** Never rely on red-vs-green distinction to carry meaning.

## Typography

### Classifying the feel

| Category | Feel | Open-licensed examples (Google Fonts) |
|---|---|---|
| Geometric sans | Modern, clean, tech | Poppins, Montserrat, Outfit, Manrope |
| Humanist sans | Friendly, approachable | Nunito Sans, Source Sans 3, Fira Sans |
| Grotesk / neo-grotesk | Neutral, confident | Inter, Archivo, Work Sans |
| Old-style serif | Traditional, literary, artisanal | EB Garamond, Cormorant, Libre Caslon |
| Transitional / modern serif | Elegant, editorial, luxury | Playfair Display, Bodoni Moda, DM Serif Display |
| Slab serif | Sturdy, retro, industrial | Roboto Slab, Zilla Slab, Arvo |
| Script | Personal, romantic, handmade | Dancing Script, Great Vibes, Pacifico |
| Display | Distinctive personality | Use sparingly; check legibility |

### Rules of thumb

- One typeface for the logo (two at most: name + tagline).
- Tagline: smaller, often a contrasting style (e.g. spaced caps sans under a serif name), never competing.
- Modify, don't just typeset: a custom ligature, a cut, a shared stroke, or a symbol replacing a letter makes the wordmark ownable.
- Check the license: SIL Open Font License fonts are safe for logos; many commercial fonts require a specific license for logo use.
